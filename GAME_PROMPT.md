# The one prompt

This whole game came from a single prompt, typed once, built by an AI
coding agent while the camera watched:

> Build me a tiny browser game in one HTML file: a cat leaping between
> rooftops at dusk. One button to jump — press at the right moment to
> land on the next roof, miss and you fall. Score +1 per roof landed,
> speed rises as you score, dusk skyline with a big moon, game over
> screen with restart. Make it juicy: squash and stretch, dust puffs
> on landing, a little flash on a perfect landing.

The result is `game.html`: no assets, no dependencies, one file.
Open it in any browser, click / tap / press space to jump.

The video in the entry post shows the prompt going in, the agent
building, and this exact game running — score, speed-up, perfect
landings, fall and restart included.
